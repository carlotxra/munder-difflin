# G8 A/B: role after a real compaction, 2026-10-18

`npm run eval -- --build stable --only G8 --runs 3 --matrix <4 arms> --max-usd 12 --accept-uncapped --keep`

G8 = three turns of one session: long planning notes to summarise into `board.md`, then
`/compact`, then a one-line code change with Kevin idle. Michael passes if he still delegates.
**All 12 runs compacted** (checked per run: Claude `compact_boundary`, Copilot
`session.compaction_complete`). Claude total $7.30.

## What it says

- **One compaction did not make Michael drift on either engine**, with or without T-051 or V2. In
  every run he still delegated the change to Kevin and touched nothing himself. So G8, as built,
  does not separate the arms: the protection T-051 and V2 add after compaction is not needed for
  this level of history.
- Copilot with the native instructions file used about 10% fewer tokens (843k vs 939k median). Treat
  that loosely: Copilot's multi-step token totals may be over-counted (see eval/README.md), equally
  for both arms.
- On Claude, V2 cost the same as upstream ($1.18 vs $1.22 median).

## Making G8 harder (if wanted)

The drift these changes guard against is more likely after long sessions with several compactions
and a request that invites doing the work directly. Options: repeat the history and compaction steps
two or three times, make the history include god editing his own files often, and phrase the final
request as urgent. Each extra step adds about $0.40 per Claude run.
