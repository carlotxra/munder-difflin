# Native instruction channel, Copilot A/B, 2026-10-18 (T-051)

`npm run eval -- --build t051-native-instructions --runs 2 --matrix <copilot nativeInstructions [], copilot default> --accept-uncapped`

- All fixtures (S1–S8, G1–G7, G9–G12), 2 runs each, Copilot CLI 1.0.98 default model
  (`gpt-6-luna`), `--perm safe`, cost levers on, god prompt V2 on in both arms. No Claude spend.
- Arm A: `nativeInstructions: []`, so the hive prompt is sent as the first message (upstream).
- Arm B: the default, so the first message is a short kick that names the instructions file.

## Results

| | Arm A (prompt as first message) | Arm B (native file + kick) |
|---|---|---|
| S1–S8 | 11/16 | 11/16 |
| G1–G12 | 22/22 | 21/22 |
| **Total** | **33/38** | **32/38** |
| Sum of median tokens (19 fixtures) | 5.51M | 5.44M (−1%) |

Per fixture, the arms differed by at most one run (S2, S5, S7, G11), and in both directions.
S6 (closing time with work in progress) failed in all four runs on both arms: the Copilot worker
leaves the WIP uncommitted. That is worker behaviour, unrelated to this change.

## What it can and cannot say

- **For Copilot, this tests removing a duplicate, not the channel itself.** Since T-002 the fork has
  written the hive prompt into Copilot's `copilot-instructions.md` *and* sent it as the first
  message. Arm A still has the file. So the result is: dropping the second copy costs nothing in
  pass rate and saves about 1% of tokens.
- **The channel's main benefit is not measured here.** These are one-shot `-p` runs, so nothing is
  compacted. The point of T-051 is that standing instructions survive compaction and carry more
  weight over a long session. That needs a resume-based runner (fixture G8, still unbuilt), or an
  engine that never had the file. OpenCode is that engine, but it runs in the eval only with
  `--perm live`.
- **Eval noise on Copilot, in both arms:** `view` of hive files (`PROTOCOL.md`, `registry.json`,
  `tasks.json`, …) was refused 30+ times even though the hive root is passed with `--add-dir`, and
  one `git merge --ff-only <sha>` was refused (G11#1, arm B) although `git merge` is allowed and
  succeeded in other runs. Worth a look before reading small differences in Copilot numbers.

## Conclusion

Safe to keep on by default for Copilot (no loss, slightly cheaper). The case for it rests on the
compaction argument and engine documentation, not on this run. Measure it properly once G8 or an
OpenCode safe mode exists.
