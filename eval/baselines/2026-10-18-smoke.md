## What it says

- **Explicit rules are followed on both engines.** G7 and G9 to G12 put the rule in god's
  `memory.md`, and both engines kept to it, including judgement calls (G12).
- **G4 fails on both, for the same reason: the instructions contradict each other (plan P4).**
  With spawning off, god's prompt leaves out the spawn instructions, but `PROTOCOL.md` and
  `COMMANDS.md` still describe the spawn queue ("runs if the operator turns it on"). Both engines
  read it and filed a request that will never start. Claude then told the human the task was
  "handed to a new worker". Phase 2 (T-052) should say plainly that god cannot spawn when the
  toggle is off, and the docs should match.
- **Copilot is weaker on the human-ask format (G5).** It is the only shape rule given inline and
  never repeated in memory. Phase 2's worked good/bad example targets this.
- **Eval noise:** Claude's safe mode denied compound `cd <hive>; …` commands in every run (1–2
  extra calls each). It doesn't change outcomes, but it inflates calls and cost.
